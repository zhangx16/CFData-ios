# CFData iOS 手机界面设计与验证

2026-10-26。使用用户指定的 `ui-design-iteration` skill，先提取现有产品，重新组织手机端层级，再进行浏览器审阅和产品接入。

## 设计来源与范围

设计源是当前产品 `combined_refactor/index.html` 的系统字体、蓝色强调色、浅灰底色及深色配色；不是另行选择的商业模板。已有页面作为第一份可运行参考，因此从 skill 的提取 / intake 流程开始。用户明确授权重新设计手机布局，不要求复制原前端。

新页面位于 `ios/web/index.html`，保留源产品的视觉语汇，调整信息架构：

- 优选：来源切换、分组基础参数、折叠高级参数、固定开始 / 停止按钮。官方自动模式依次执行扫描、详细延迟测试、下载测速。
- 结果：真实测量指标、按 IP 分组的单列列表、搜索 / 筛选 / 排序、单点和批量测速、CSV / TXT / 剪贴板 / GitHub 导出。
- 设置：测速源、速度阈值、深浅色、代理、GitHub 上传配置、运行记录。
- 条件界面：未连接、准备中、运行中、停止中、错误、空结果、筛选无结果、长 IPv6、文件导入、自定义 URL、筛选弹窗、导出弹窗、确认弹窗。

仅移动端构建替换 Go 的嵌入 HTML，上游扫描逻辑和桌面前端保持原样。用户请求包含产品改造，故在完成静态审阅后继续接入实际 WebSocket 协议与原生能力；skill 自身的草稿流程不承担网络测量正确性的证明。

## Tokens 与设计决定

| 属性 | 来源与用途 |
| --- | --- |
| `--gap:16px`、`--room:1.5` | 16px 基础间距，24px 分组间距，按手机内容密度调整 |
| `--fs:17px` | 系统字体与手机表单正文 |
| `--small:13px`、`--label:15px`、`--title:22px`、`--large:32px` | 注释、次级操作、指标、页面标题；共五档字体 |
| `--ratio:1.294` | 记录正文与小标题的比例；保留明确的字号档位 |
| `--measure:640px` | 平板 / 桌面预览仍使用手机工具的单列内容宽度 |
| `--radius:16px`、`999px` | 分组与按钮的主圆角、分段选项与开关的胶囊圆角 |
| `--ink`、`--surface`、`--line`、`--bg` | 提取原产品配色；深色主题独立映射 |
| `--accent:#1d4ed8`、`--success:#076b4b` | 从原蓝 / 绿状态色调深，修复浅色背景下的 AA 对比度 |
| `--edge:1px`、`--shadow:0` | 分隔实际表单行；静止面板不加阴影，只有短提示浮层使用阴影 |
| `--dur:160ms`、`--ease:cubic-bezier(.2,0,0,1)` | 进度与开关的短过渡；遵循减少动态效果设置 |
| `--hue` | 不绑定。强调色是完整颜色，避免色相滑块破坏已验证对比度 |

无背景渐变、无装饰图、无图标顶置功能卡片行。底部导航图标用于页面识别。结果汇总是一个分隔指标组，详细结果使用垂直列表。

## 已执行的验证

- 实际浏览器：Linux WebKit 与 Chromium。WebKit 与 iOS 使用同类引擎，但不等同于 iPhone 真机测试。
- 交互：官方自动三阶段链路、自定义 IPv6、停止 / 返回前台、筛选、原生导出消息、剪贴板消息、主题、重载恢复。网络与原生接口在浏览器测试中使用明确的 mock，未把模拟结果当成真实测速。
- 响应式宽度：320、375、390、430、767、768、1280px；检查三个页面及折叠区展开后的横向溢出。
- 触控：检查可交互区域至少 24×24px；主要按钮 / 导航至少 44px。开关和复选框由整行标签扩大点击范围。
- 键盘：筛选弹窗用 Enter 打开、Escape 关闭并恢复焦点；交互元素保留可见 focus outline。
- skill 面板审阅：375 / 768 / 1280px，浅色 / 深色三个页面，以及手机自定义展开、筛选与导出弹窗，共 24 个状态。`audit.json` 中没有文字对比度失败；实际使用两种圆角、五档字体、无渐变。
- 审阅工具与选择快照只存在临时目录，不进入应用。原生 Go 测试及最终 IPA 编译由构建流程另外验证。

## 接入与边界

运行时仅使用 `ios/web/index.html` 及原生生命周期桥接 `ios/Resources/ios-bridge.js`，不依赖 CDN、Node 或额外前端服务。最近一次结果在本机最多缓存 1000 条；当前会话可筛选和导出完整结果。访问令牌只保留在当前页面内存，上传前明确展示目标仓库与路径。

没有 iPhone 真机点击、系统分享扩展或真实蜂窝网络测速结果；浏览器 mock 测试不会替代这些验收。
